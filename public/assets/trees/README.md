# Árvores 2D — ambientação de A FLORESTA MENTE

Origem: arquivo **`avores 2d.zip` fornecido pelo usuário** neste chat, contendo `00.png`, `01.png`, `03.png` e duas imagens de prévia.

`forest-trees.webp` é um atlas **WebP sem perdas e com transparência**, organizado assim: `tree00` (146×188), `tree01` (129×211) e `tree03` (89×126), sem alterar as cores dos PNGs originais.

Finalidade: exclusivamente **cenografia atrás das plataformas, personagens e avisos** nas quatro fases. As árvores deste arquivo não criam colisões, interações, desafios ou pacotes de rede.
